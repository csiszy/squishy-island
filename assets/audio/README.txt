SQUISHY ISLAND SOUNDS - ready-to-use audio files
================================================

sfx/    38 sound effects, 44.1 kHz 16-bit WAV (stereo), trimmed, peak -3 dBFS
music/  14 seamless music loops, Ogg Vorbis (~q5), peak -1.5 dBFS
        Each file is exactly one loop: set it to loop in the engine and it repeats without a gap.

Where each sound plays and which place each song belongs to: see sound.html in the design book.
